About:
The program uses separate functions to perform loan calculations and check applicant eligibility.

Functions Used:
1. caclculate_emi() - Calculates the monthly EMI using the principal amount, annual interest rate and loan tenure.
2. total_payable_amount() - Calculates the total amount payable throughout the loan tenure.
3. total_interest - Calculates the total interest paid on the loan.
4. check_eligibility - checks whether the applicant is eligible based on the EMI and monthly income.
5. validate_inputs - Validates all user inputs.

Input parameters:
1. Principal amount
2. Annual interest rate
3. Loan tenure (months)
4. Monthly income

Output:
1. Monthly EMI
2. Total payable amount
3. Total interest
4. Loan eligibility status

Concepts applied:
1. Python functions
2. Arithmetic Operators
3. Exponent Operator
4. If-Else Conditions
5. Input Validation
6. String Formatting
